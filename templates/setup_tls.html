The portal handles its own TLS via Let's Encrypt with the DNS-01 challenge through Cloudflare. This means the box never needs to be reachable on port 80 from the internet.

Before continuing — create a DNS A record.

The portal hostname has to resolve to this appliance, or clients on the school network won't be able to reach it and Let's Encrypt won't be able to confirm the cert is yours. Create this record in whichever DNS your client devices use (Cloudflare for public access, AD / on-prem DNS for an internal-only setup — usually both): 

Type:   A
Name:   {{ _portal_host or 'portal.example.org' }}
Value:  {{ _appliance_ip or '' }}
TTL:    Auto (or 5 minutes while testing)
Proxy:  Off  (Cloudflare: "DNS only", gray cloud — orange cloud breaks RADIUS / WLAN traffic)

The Cloudflare API token below is for cert validation (DNS-01) — it does not create the A record above. That's a separate one-time manual step.

How to create the Cloudflare API token
  1. Open dash.cloudflare.com → My Profile → API Tokens.
  2. Click Create Token → "Edit zone DNS" template.
  3. Permissions: Zone → DNS → Edit and Zone → Zone → Read.
  4. Zone Resources: scope to just the zone that owns your portal hostname (e.g. example.org).
  5. Create → copy the token. You won't be able to see it again.
  6. Paste it below — the wizard verifies it with Cloudflare before saving.
