This wizard collects everything the captive portal needs to run: branding, storage, email delivery, Google OAuth, SmartZone API access, RADIUS shared secret, and TLS certificate setup.

What it does at the end:

  • Writes your answers to .env in the project directory.
  • Sets SETUP_COMPLETE=true so the portal boots normally next time.
  • Restarts the service so the new configuration takes effect.

Before you start, have these ready:

  • The hostname you'll serve the portal on (e.g. portal.example.org).
  • Access to your DNS — you'll need to create an A record pointing that hostname at this appliance's IP. The wizard will show the exact values to enter once you've picked the appliance IP in the Network step. (This is separate from the Cloudflare API token below, which is only used to validate the cert at issue time, not to create the A record.)
  • SMTP relay details (host, port, optional credentials).
  • Google OAuth client ID + secret (console.cloud.google.com).
  • SmartZone controller hostname, API service-user credentials, and API version.
  • A Cloudflare API token with DNS edit on the zone for your portal hostname.

You can stop and resume — answers are kept in your browser session as you go. Nothing is written to disk until the final review step.
